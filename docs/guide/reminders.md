# 提醒中枢

> 所有模块的日期字段自动派生为提醒，统一在这里管理。

## 三级分组

| 分组 | 含义 | 颜色 |
|---|---|---|
| 已逾期 | 到期日已过 | 🔴 红 |
| 未来 7 天 | 7 天内到期 | 🟠 橙 |
| 提前量内 | 在提前提醒窗口内 | 🟡 黄 |

## 筛选

筛选条支持四个维度叠加：

- **级别**：已逾期 / 7 天 / 提前量 / 已处理
- **成员**：按归属成员过滤
- **模块**：按来源模块过滤
- **时间窗**：今天 / 7 天 / 30 天 / 全部

筛选条件自动持久化，下次打开保持。

## 处理动作

| 动作 | 效果 |
|---|---|
| 完成 | 从活跃列表消失；可在"已处理"视图恢复 |
| 续期 | 证件/保险/合同类：弹出日期选择器，写回台账行 |
| 延后 | 运行态操作（不改台账日期），延后日到后重新出现 |
| 忽略 | 永久隐藏（可在已处理视图恢复） |
| 定位 | 打开台账原文档 |

## 导出日历

筛选行右侧"导出日历 (.ics)"把**当前筛选结果**导出为日历文件（每条提醒 = 到期日全天事件），可导入手机/电脑日历 App 获得系统级提醒；含高后果模块（健康/证件/财务/儿童相关）时导出前会先确认。

## 已处理视图

筛选为"已处理"时显示所有已完成/忽略/本期已办/备忘已办的事项，每条可**恢复**回活跃列表。

## 批量操作

点击"批量"进入选择模式 → 勾选或全选 → 批量完成/延后 7 天/忽略。

## 每日通知

- 每天 `notifyHour`（默认 8 点）后首次扫描弹一次摘要
- 每周日在下次扫描时弹"未来 7 天"预告
- 逾期事项首次被发现会立即提示
- 静默时段（默认 22:00–8:00）不弹任何通知
