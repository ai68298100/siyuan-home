# 证件管理

> English version: [certs.en.md](certs.en.md)

> 追踪全家证照的效期，到期前自动提醒。

## 录入

台账页 → 证件管理 → 填写快速表单：

| 字段 | 说明 |
|---|---|
| 名称 | 证件名称（如"身份证"） |
| 成员 | 归属成员（可选） |
| 分类 | 身份证/护照/港澳通行证/台湾通行证/驾驶证/职业资格证/从业资格证/毕业证/学位证/职称证… |
| 到期日 | 效期截止日 |
| 签发规则 | 6 年一换 / 10 年一换 / 长期 / 签注另计 |
| 存放地点 | 物理存放位置 |
| 备注 | 自由文本 |

选择分类后，快速录入会追加该证件的专属字段。例如：身份证提供住址摘要、签发机关和人像面/国徽面；护照提供国籍、出生地和资料页；驾驶证提供准驾车型、初次领证日和审验日；学历、学位、资格和职称证提供学校/专业/等级/发证机构等字段。证件号码只建议录入后四位，完整号码留在原件中。

## 快速上传和下载

证件快速录入卡提供“选择照片/PDF”按钮。手机端可直接调用相机，身份证、驾驶证等类型会分别显示人像面/国徽面或证件扫描件入口；桌面端可选择图片或 PDF。填写名称和分类后即可连同附件一次保存，上传失败会保留失败文件供重试。

在证件详情中，每个附件都有“预览”和“下载”按钮。预览与下载只访问当前思源实例的 `/assets/` 资源；下载文件名使用上传时的文件名。附件仍受思源工作空间权限和备份机制约束，插件不会把证件图片发送给 AI 服务。

## 提醒规则

- **到期日**：默认提前 **90 天**提醒（可在 设置 → 提醒设置 调整）
- **签注/审验日**：默认提前 **60 天**提醒
- 状态为"已过期/已换新/已注销"的行**不再提醒**

## 续期流程

1. 提醒中枢看到证件即将到期
2. 点击"续期" → 选择新到期日 → 保存
3. 台账行的到期日自动更新，旧提醒消失、新提醒按新日期生成
4. 历史续期记录在详情抽屉底部可见

## 换证链

证件换新证（如护照换发）时，在旧证详情抽屉点击"关联新证"并选择新证行——抽屉会双向显示「→ 新证 / ← 旧证」，换证历史一目了然；数据存在台账行上，删任一方即断链。

## 联系人

编辑详情时可填写"对接人（人脉）"——如果安装了小驴人脉插件，点击"从人脉选择"可搜索并选人。快照格式为 `名称 [docId]`。

## 常见问题

**Q: 到期日填了但没提醒？**
A: 检查状态列是否为"有效"（非有效状态不提醒）；检查提前量设置。

**Q: 想让某条证件永久不再提醒？**
A: 使用"忽略"（可恢复）或修改状态为"已过期/已注销"。
