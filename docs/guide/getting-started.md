# 快速上手

> 5 分钟完成首次设置，看到第一条到期提醒。

## 1. 启用插件

安装后，在思源 → 设置 → 集市 → 下载 页启用 **小驴管家**。启用后顶栏出现 🏠 图标。

## 2. 首次引导

首次打开管家面板会出现两步向导：

1. **家庭构成**：选择你和家人的角色（自己/配偶/子女/老人…）。这只用于推荐模块，不会自动创建成员。
2. **推荐模块**：根据构成预选模块（如选了"子女"会推荐育儿/上学/零花钱）。确认后点击"✓ 完成"。

完成后管家会自动为启用模块创建台账笔记本（默认"🏠 小驴管家"）。建库需要几秒。

> 跳过引导也没关系——之后可以随时在 设置 → 关于 → "重新运行引导" 或手动在模块开关中启用。

## 3. 添加成员

进入**成员**页签，输入姓名和角色，点击"＋ 添加"。

- 生日支持**农历**（勾选"农历"标记，闰月自动处理）。
- 成员会同步到台账数据库，各模块的"成员"列可选择归属。

## 4. 录入第一条证件

进入**台账**页签 → 选择"证件管理" → 填写：

- **名称**：如"身份证"、"护照"
- **成员**：选择归属成员
- **到期日**：选择到期日期

点击"＋ 新建"即完成。行会出现在下方表格和思源原生文档中。

## 5. 查看到期提醒

进入**提醒**页签，系统自动将台账中的日期字段转为提醒：

- 🔴 **已逾期**（红色）
- 🟠 **未来 7 天**（橙色）
- 🟡 **提前量内**（黄色，证件默认 90 天）

每条提醒可以：**完成** / **续期**（更新到期日）/ **延后** / **忽略** / **定位**（打开原文档）。

## 6. 日常使用

- **快速备忘**：总览页底部输入框，不需台账。
- **块菜单存入**：选中文本 → 右键 → "存入小驴管家"（文本进常用语，URL 进书签）。
- **状态栏角标**：思源底部状态栏显示今日到期数。
- **搜索**：台账页搜索框（名称/备注）。
- **导出**：设置 → 关于 → 导出 CSV / 导出设置。

## 遇到问题？

- 台账误删 → 设置 → 模块开关重开 → 幂等重建
- 设置损坏 → 自动回退默认值 + 留 `.corrupted.json` 标记
