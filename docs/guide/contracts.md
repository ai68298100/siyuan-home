# 合同与文件

> 追踪租房、装修、劳动、物业等各类合同的到期日与对接人。

## 录入

台账页 → 合同与文件 → 填写快速表单或详情编辑：

| 字段 | 说明 |
|---|---|
| 名称 | 合同名称 |
| 分类 | 租房/装修/购房/劳动/物业/其他 |
| 对方 | 合同对方名称 |
| 对接人（人脉） | 从小驴人脉选择，或手填 |
| 开始日 | 合同起始日 |
| 到期日 | 合同到期日 |
| 押金 | 金额 |
| 附件 | 扫描件/照片 |

## 提醒规则

- **到期日**：默认提前 **90 天**提醒
- 终止/过期的合同**不再提醒**

## 对接人

"对接人"字段支持两种输入方式：

1. **手动输入**：直接填写姓名和联系方式
2. **从人脉选择**：点击"从人脉选择"按钮 → 搜索小驴人脉 → 选人 → 自动填入快照

快照格式为 `名称 [docId]`，便于后续追溯。绑定后可在小驴人脉中查看与该联系人的完整交集记录。

## 续约流程

1. 到期前收到提醒
2. 决定续约 → 点击"续期" → 输入新到期日
3. 决定不续 → 将状态改为"已终止"或"已到期"→ 停止提醒
