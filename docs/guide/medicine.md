# 药箱管理

> 追踪药品效期与库存余量，低库存和临期自动提醒。

## 录入

台账页 → 药箱管理 → 填写快速表单：

| 字段 | 说明 |
|---|---|
| 名称 | 药品名称 |
| 分类 | 处方药/非处方药/外用药/器械/保健品 |
| 到期日 | 效期截止日 |
| 库存数量 | 当前存量（数字） |
| 低库存阈值 | 低于此数量时提醒 |
| 存放位置 | 如"家庭药箱" |

## 双规则提醒

药箱有两条独立的提醒规则：

1. **效期提醒**：到期日前 30 天提醒（可配置）
2. **低库存提醒**：库存数量 ≤ 低库存阈值时立即提醒

两条规则独立触发——一盒药可能同时临期又低库存，会出现两条提醒。

## 低库存语义

- 库存数量 **= 或 <** 阈值 → 触发提醒
- 库存数量为 **0** 算有值（触发）
- 库存数量或阈值**缺列/缺值** → 不评估（不误报）
- **补货**到阈值之上 → 下次扫描自动解除（不需要手动关闭）

## 人脉关联

药箱行也可以填写"对接人"字段——记录推荐的医生或药师。如果安装了小驴人脉，可从成员页或详情抽屉选择联系人。

## 处方转入药箱

健康模块的处方/用药记录行，详情抽屉有"转入药箱"按钮——一键在药箱建同名行（成员关系自动复制），成功后按钮变灰防止重复转入。

## 购入入库到囤货

购物模块行填了数量后，详情抽屉可"入库到囤货"——同名囤货行数量累加（无同名则新建），确认框会报匹配情况；入库后低库存提醒即时重算。
