# 成员管理

> English version: [members.en.md](members.en.md)

> 家庭成员是小驴管家所有模块共用的组织维度。

## 添加成员

成员页 → 输入姓名和角色 → 点击"＋ 添加"。

| 字段 | 说明 |
|---|---|
| 姓名 | 必填 |
| 角色 | 自己/配偶/伴侣/子女/老人/其他亲属/其他 |
| 生日 | 可选，支持农历 |
| 农历 | 勾选后生日按农历计算 |

成员添加后会自动在成员台账数据库中创建对应的行（双写），后续编辑会同步更新。

## 编辑成员

点击成员卡上的"编辑"按钮 → 修改字段 → 保存。

- 改名 → 台账行的名称列同步更新
- 清空生日 → 台账行的生日列同步清空
- 无关联行的成员保存时会自动补建台账行

## 删除成员

点击"删除" → 确认。**仅移除设置侧引用，台账行保留**。如果该成员有关联的提醒或筛选，会自动复位。

## 关联人脉联系人

如果安装了小驴人脉插件（v0.4.1+），可以给成员关联人脉联系人：

1. 点击成员卡上的"关联联系人"
2. 在弹窗中搜索人脉联系人
3. 选中后保存快照（`名称 [docId]`）

解除关联点击"解除关联"即可。快照仅存储在管家侧，**不会改写人脉数据**。

## 成员统计

每个成员卡显示：

- **待办统计**：按模块聚类的 top-3 待办计数（来自当前扫描）
- **提醒计数**：⚠ 标记 + 总数
- **农历标记**：🌙 图标

## 导出联系人 (.vcf)

工具行右侧"导出联系人"把全部成员导出为 vCard 4.0 文件（称呼、公历生日、备注、角色），可导入手机通讯录。生日按农历记的成员不会写入生日字段（不做农历→公历换算）；姓名/生日属个人信息，导出前会确认。

## 成员过滤

总览页和提醒页的成员 chips 可按成员过滤——选中后只显示该成员相关的事项。删除成员时指向它的失效筛选会自动复位。
