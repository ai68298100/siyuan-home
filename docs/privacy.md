# 隐私声明与共享边界（Privacy & Boundaries）

> English version: [privacy.en.md](privacy.en.md)
> 
> 小驴管家（Lv Home）v0.5.7 · 现行事实版（2026-10-15）

**核心原则：你的数据只保留在你的本地设备与你的思源工作空间内，插件作者不收集、不中转、不上传任何数据。**

## 数据存储与归属

- **台账数据**：所有家庭台账（证件、药品、车辆、资产、健康等）均以**思源笔记数据库与文档块**的形式存储在用户本地工作空间（`data/` 目录），由思源内核直接管理。
- **设置与运行态**：插件偏好配置、提醒规则覆盖、运行态记录（延后、忽略、快速备忘、命名视图等）存储于工作空间 `data/storage/petal/siyuan-home/` 目录，完全归属于用户本地。
- **无外部数据沉淀**：插件作者不架设任何中转服务器、数据收集服务器或备份服务器。

## 共享、协作与同步边界

- **家庭共享机制**：家庭成员之间的多端协作完全依托思源笔记自带的**工作空间共享、用户权限控制与多端同步服务**（官方云端或第三方 S3/WebDAV）。小驴管家不自建用户账号体系，也不提供独立的权限隔离系统。在多设备共享工作空间时，所有具备该工作空间访问权限的成员均可查看台账内容。
- **同步边界**：当用户开启思源同步时，台账文档与插件存储会随思源工作空间一并同步流转至用户指定的云端，相关数据的传输加密与云端存储安全性完全由思源官方或用户配置的第三方存储平台保障。

## 冲突、撤回与备份边界

- **多端冲突处理**：在多端并发编辑或离线后同步产生冲突时，数据冲突严格遵循思源内核的**块级协同与冲突处理策略**。插件不劫持、不强行覆盖底层版本，确保数据不静默丢失。
- **撤回与历史版本**：若发生误删或意外修改，用户可利用思源内置的**文档历史（Doc History）**与快照对比功能快速回退恢复台账数据。此外，提醒中枢支持 5 秒全局撤销底栏（`UndoSnackbar`）快捷撤销误完成或误延后操作。
- **备份与恢复**：
  - **运行态与配置备份**：用户可在插件「设置 → 关于」中一键导出脱敏诊断包或设置 JSON 备份文件；
  - **台账全量备份**：台账数据作为原生思源文档，随思源整体数据备份（快照归档/工作空间导出）一并保存。

## 网络行为边界透明度声明

- **插件不主动外联**：插件默认处于完全离线运行状态，核心计算（日期计算、退休精算、过敏冲突筛查、双日期派生、拼音检索等）均在本地运行。拼音字典（`pinyin-dict.json`）等资源均内置于本地插件包，绝不请求外部 CDN。
- **用户授权的外联场景**（环境非绝对物理隔离）：
  - 🔔 **Webhook 推送（可选）**：仅在用户主动于「设置 → 提醒推送」中配置并开启 Bark / ntfy 时，插件会在设定时刻向用户指定的接收端发送纯文本到期摘要。
  - 🔍 **图片 OCR 识别（可选）**：用户在台账详情中主动点击 OCR 时，由思源宿主调用用户在思源全局设置中选定的引擎；若选用外部 AI 引擎，每次调用前均有显式风险确认。
  - ☁️ **思源原生网络行为**：包括思源软件更新、集市插件检查以及思源云端同步，属于思源宿主程序行为，不受插件干预。

## 敏感信息防护与脱敏

- **密码零存储**：虚拟资产（`assets-virtual`）仅记录“密码存放位置索引/密码提示”，严禁录入并绝不存储真实明文密码。
- **证件与卡号掩码**：证件号码、银行卡号、手机号码等敏感字段在表格与看板中默认星号掩码展示（防侧窥）。
- **脱敏复制机制（MOD-04）**：台账详情抽屉提供「复制为文本（脱敏）」能力，智能对 18 位身份证、手机号、保单号与密码提示等关键敏感隐私打码，方便跨聊天工具和客服场景分享。
- **XSS 安全转义（SEC-01）**：所有动态拼接的用户输入标题、备注及弹窗内容，均通过 `escapeHtml` 严密转义，杜绝脚本注入风险。

## 数据导出分级管控

CSV、.ics 日历与 JSON 导出全部在前端本地由 JavaScript 生成，不经任何网络接口，并实施分级确认警示：
- **高风险核心模块**（健康、育儿、证件、资产、合同等）在 CSV 导出前点名警示包含真实明文；
- **配置导出**明确告知包含家庭成员列表与提醒记录；
- 导出文件生成后由浏览器/思源保存至用户本地磁盘，请用户自行妥善保管。
