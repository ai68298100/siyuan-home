# 隐私声明（Privacy）

> 小驴管家（Lv Home）v0.2 · 生效于首次发布

**一句话：你的数据只在你自己的设备与你的思源笔记里，我们不收集任何东西。**

## 数据存储

- 台账数据（证件、成员、提醒规则引用等）以**思源笔记数据库与文档**形式存储在你的本地工作空间（`data/` 目录），随思源自身同步/备份机制流转。
- 插件设置与提醒运行态（延后/忽略记录、快速备忘）存于 `data/storage/petal/siyuan-home/`，同样只在你的工作空间。
- 我们（插件作者）**没有服务器**，不接收、不中转、不备份你的任何数据。

## 明确不做的

- ❌ 无遥测、无埋点、无崩溃上报
- ❌ 不请求网络权限（内核 API 全部本机调用）
- ❌ 不存任何密码（虚拟资产模块只提供"密码存放位置索引"文字字段）
- ❌ 证件号等敏感字段仅支持录入后四位（脱敏设计）

## 通知

到期提醒使用系统本地通知，标题只显示"N 件事需要处理"级别的摘要，**不播报具体证件名或金额**（可在设置调整）。

## 导出

CSV/JSON 导出在插件内本地生成（不走网络），且带分级警示：

- **高后果模块**（健康、育儿、证件、保险、资产、合同、药箱、上学）的 CSV 导出前会点名类别并要求确认——文件将完整导出当前可见行；
- **设置 JSON** 导出前会提示保管责任（含成员档案与提醒运行态，不含台账正文）；
- 模板"生成文档"（家长会记录、体检年度计划）会在台账笔记本内创建思源文档，创建前确认落点——文档会随思源自身的同步/分享范围流转。

导出文件请妥善保管，避免转发。

## 变更

本声明随版本更新维护于仓库 `docs/privacy.md`；实质性变更会在 CHANGELOG 标注。
