# 隐私与数据安全声明（Privacy & Data Governance）

> 小驴管家（Lv Home）· 最新修订生效于 2026-10-19

**核心原则：本地优先 · 数据不锁定 · 隐私零妥协 · 权责清晰。**

---

## 1. 数据存储与同步边界

- **业务台账数据**：所有的家庭成员、证件档案、资产台账、健康记录等结构化数据，均以**思源原生数据库（属性视图 Attribute View）与文档块**的形式存储在用户本地思源工作空间的 `data/` 目录下。
- **配置与运行态**：插件的用户设置、提醒运行态（延后/忽略/置顶/命名视图、临时备忘流水）存储于工作空间的 `data/storage/petal/siyuan-home/` 目录下。
- **多设备同步边界**：插件本身**不自建任何云端服务器、数据库或同步中继**。用户若开启思源官方云端同步或自建 S3 / WebDAV 同步，数据将随思源同步通道自动在多端流转。同步链路的传输加密、数据中心存储与凭据安全均由思源宿主及用户所选同步服务商提供，插件不拦截、不解析亦不留存同步凭据。

---

## 2. 访问控制与协作权限

- **会话与权限承载**：插件没有独立的账号体系或逐用户 ACL（访问控制列表）。插件的前端界面与后台 API 调用直接沿用当前思源客户端的主会话权限。
- **敏感数据可见性**：
  - 证件号码、联系方式等敏感信息在界面表格与抽屉中提供**前端脱敏遮罩（掩码）**与按需查看切换；但请注意：**前端遮罩仅为防窥显示层，不等于底层字段级数据库加密**。
  - 工作空间拥有者或具备该笔记本读取权限的协作者，均可在思源原生视图或文档中查看台账内容。请根据家庭或团队信任边界谨慎配置工作空间共享。

---

## 3. 多端冲突、撤回与备份恢复机制

- **多端并发与冲突**：当多台设备同时离线编辑同一台账行或同名成员时，最终合并与冲突解决遵循思源底层的文档块同步策略。为避免写入撕裂，插件在关键创建链路（如新建行、新建成员）中强制执行“回读指纹验证”，超时未确认时标记为“待确认”而非盲目重试。
- **删除与撤回边界**：
  - 在台账中删除单行或删除文档后，思源原生回收站会保留被删块的历史记录；
  - 插件存储侧（`settings.json` 与 `hub-runtime.json`）支持在配置导入前自动生成备份副本（`settings.pre-import.json`），并在文件损坏时保留 `.corrupted.json` 诊断标记；
  - 批量删除或批量改派等破坏性操作前均提供不可逆二次确认，插件不提供全局“一键无损撤销所有写操作”能力。

---

## 4. 网络行为与外部联通说明

- **零遥测、零埋点**：代码内完全不包含任何用户行为统计、崩溃上报 SDK 或第三方分析代码。
- **关于“不主动外联”的诚实边界**：
  - 插件核心业务逻辑（台账查看、提醒规则派生、日历计算、拼音检索、CSV 导入导出、诊断分析等）**100% 在本地离线执行**，完全不需要网络连接。
  - **唯一受控网络出口**：用户在“设置 → 提醒中枢”中**显式开启并填入**的 Webhook 地址（如自行搭建或使用的 Bark、ntfy 推送）。未配置或关闭时，插件不会发出任何 HTTP 外部请求。
  - **宿主环境说明**：声明“插件不主动外联”仅代表本插件源码的行为，**不代表整个思源运行环境绝对无网络**。思源内核自身的更新检查、集市包下载、同步上传、用户配置的思源 AI 模型接口外发等网络行为均属于思源宿主平台的独立职责。

---

## 5. 数据导出与携带

所有导出文件均在客户端本地生成，绝不上传到任何远程服务：

- **高后果数据导出提示**：导出涉及健康、育儿、证件、资产等模块的 CSV 表格前，弹窗显式提示文件将包含完整明文内容（包含已录入的真实证件号），提示妥善保管；
- **脱敏分享**：台账详情抽屉提供「复制为脱敏文本」及「生成分享卡图片」，自动隐藏身份证、手机号、邮箱中间敏感字符，方便家人沟通时安全复制；
- **系统诊断包**：在设置页导出的诊断包已经过脱敏处理，仅包含模块行数、schema 校验状态和错误堆栈，**绝对不包含任何家庭成员姓名、身份证号或私人备注**。

## 6. 变更与监督

本声明作为项目的基线安全契约，随版本演进而更新维护于 `docs/privacy.md`。任何涉及数据流转或隐私策略的实质变更均会在更新日志（CHANGELOG）中显著列出。
