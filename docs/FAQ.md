# FAQ

## 数据存哪里？会上传吗？

全部存在你本地思源工作空间（台账在 `data/` 的笔记本"🏠 小驴管家"内，设置在 `data/storage/petal/siyuan-home/`）。插件无任何网络行为，详见 [隐私声明](./privacy.md)。

## 多设备怎么同步？

跟随思源自带的同步机制（官方云/第三方 S3/WebDAV 均可）——台账是普通笔记本数据，设置随 storage 同步。两台设备同时编辑同一行时以思源冲突策略为准，提醒写回操作是幂等的。

## 卸载插件会丢数据吗？

不会。台账笔记本与文档完整保留，仅插件设置被清除；重装后启用模块会自动找回已有台账（幂等建库）。

## 证件号安全吗？

证件号字段设计为**只存后四位**（脱敏），扫描件等附件是本地文件，跟随思源同步（可用思源的端到端加密同步）。

## 提醒什么时候弹？

- 每日摘要：每天 `notifyHour`（默认 8 点）后首次扫描时弹一次，汇总逾期与 7 天内事项
- 逾期事项首次被发现会立即提示
- 静默时段（默认 22:00–8:00）只入列表不弹通知
- 提前量可按类型配置（证件默认 90 天、订阅 14 天、生日 7 天）

## 农历生日怎么算的？

支持农历生日（勾选"农历"标记）。闰月生日平年过平月同日；生日当天不存在（如腊月三十遇小月）时向前取最近一天（腊月廿九）；公历 2/29 平年按 2/28 提醒。

## 我不需要某模块了

设置 → 模块，关掉即可：不建库、不出现在面板、不参与提醒；**已录入数据保留**，重新开启即恢复。

## 家人也能一起用吗？

可以，而且**零额外设置**：小驴管家的全部台账都在一个专用笔记本（默认"🏠 小驴管家"）里——用思源自带的"协作/分享"把这本笔记本共享给家人，全家看到的就是同一套台账（Apple 备忘录家庭共享的同款体验，但数据还在你的思源里）。多设备同步同样跟随思源同步机制。

## 某模块台账被我误删了

设置内重新开启该模块（或点诊断重建），建库器会幂等重建空台账。已删除的行数据无法恢复（受思源回收站保护窗口限制）。

## 有哪些快捷键？

| 操作 | 入口 |
|---|---|
| 打开管家面板 | 顶栏 🏠 按钮 / 命令面板"打开管家面板"（可在设置-快捷键里自定义，默认无以免冲突） |
| 快速记录 | 顶栏 ⚡ 按钮 / 总览"快速备忘"区 |
| 面板内切换 | 总览/提醒/台账/成员页签点击 |

## 想帮忙测试？

`pnpm run make-link` 装入工作空间 → 重启思源 → 集市"下载"页启用 → 按 [回归脚本](./testing/v0.2.md) 走查，问题提 GitHub issue。
