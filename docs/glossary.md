# 术语表（小驴管家）

> English version: [glossary.en.md](glossary.en.md)

> 给非技术家庭成员的速查表：管家界面里出现的词，用一句话说清。按拼音排序。

| 术语 | 是什么 |
|---|---|
| **台账** | 一个模块的家底清单（如"证件管理""药箱管理"）。每条记录是一行，存在思源文档里，可在管家面板或思源原生视图两边编辑。 |
| **提醒中枢** | 所有模块的到期事项汇总页。日期到期前会自动出现在这里，不用自己翻台账。 |
| **提前量** | 到期日前几天开始提醒。证件默认 90 天，可在设置里按模块调整。 |
| **逾期 / 7 天内 / 提前量内** | 提醒的三级分组：🔴 已经过了 / 🟠 一周内到期 / 🟡 进入提醒窗口。 |
| **静默时段** | 不弹任何通知的时间段（默认 22:00–8:00），避免半夜打扰。 |
| **完成 / 延后 / 忽略** | 处理提醒的三种动作：办完销账 / 推迟几天再提醒 / 永久隐藏（都可恢复）。 |
| **农历标记 🌙** | 生日等日期按农历计算；闰月自动处理，不需要自己换算。 |
| **回礼 🎁** | 收了礼（人情往来里"收"方向）后，30 天自动提醒"该回礼了"。 |
| **在借** | 图书借出后还没归还的状态（影视书库模块的借出记录里）。 |
| **低库存阈值** | 囤货/药品的数量警戒线：降到这个数就提醒补货，补货后自动解除。 |
| **换证链** | 旧证件换新证时的关联记录（旧证 ↔ 新证双向可见），换证历史一目了然。 |
| **诊断信息** | 设置→关于里的"导出诊断信息"：排查问题用的脱敏数据包，不含家人隐私内容。 |
| **导入 / 导出** | 数据进出管家的通道：CSV（表格）、.ics（日历）、.vcf（通讯录）、JSON（设置）。导出都在本地完成，不经网络。 |
| **示例数据** | 设置→关于里一键生成的演示行（带【示例】前缀），体验用，可一键清除。 |

## 三个最常用的路径

1. **到期了要办什么？** → 打开管家 → 提醒页（默认按紧急程度排好）。
2. **东西放哪了 / 何时到期？** → 台账页 → 选模块 → 搜索或直接看。
3. **换手机 / 新电脑怎么办？** → 思源同步会带着管家数据走；设置可在 设置→关于 导出 JSON 备份。

## 遇到问题

- 数据"不见了"→ 先看台账页下拉里模块是否显示"缺失"，点重建即可（数据在思源文档里，很少真丢）。
