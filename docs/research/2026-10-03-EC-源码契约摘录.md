## 1. 人脉 · `window.LvContacts`（EC13/EC14/EC15）

来源：`小驴人脉/src/bridge/external-bridge.ts`（对外人员服务桥 v1，设计决策 D-0012；协议文档 `小驴人脉/docs/BRIDGE.md`）。

```ts
window.LvContacts = {
    readonly protocol: 1,
    readonly capabilities: ["searchPeople", "getPerson", "ensurePerson", "recordInteraction"],
    searchPeople(keyword?: string): Promise<{ docId: string; itemId: string; name: string; group: string; tags: string[] }[]>,
    getPerson(docId: string): Promise<BridgePerson | null>,
    ensurePerson(name: string): Promise<BridgePerson & { created: boolean }>,
    recordInteraction(personDocIds: readonly string[], meta?: {
        ref?: string;      // 幂等键，缺省 bridge:<日期>:<排序后人员>（同批不重复记录）
        date?: string;     // YYYY-MM-DD，缺省今天
        place?: string; note?: string;
    }): Promise<{ recorded: number }>,
};
```

语义与边界（源码确认）：
- 未初始化工作空间时**所有方法抛错**（"请先在小驴人脉中完成初始化"）——消费方必须 try/catch 并引导。
- `recordInteraction` 幂等键 externalRef 缺省规则已定；日期非法会抛错。
- 桥纪律声明：只提供服务，**不读取/监听其他插件私有存储**（与人脉 D-0012 一致）。
- `disposeExternalBridge` 在插件卸载时删除全局 → 探测须每次用时检查 `window.LvContacts` 存在性。

**对接落点**：EC13 办理者选择 = `searchPeople(keyword)` → 用户选人 → 保存 `{docId, itemId, name}` 快照（PM04 稳定身份）；EC15 人情交互 = `recordInteraction([docId], {ref: 管家事务 id, date, note})`（天然幂等）；联系人缺失降级快照即 `getPerson` 返回 null 的展示。

## 2. 打卡 · `window.siyuanCheckin`（EC09/EC10/EC11/EC12）

来源：`小驴打卡/src/api-contract.ts`（形式化契约 v5）+ `index.ts`（`window.siyuanCheckin = this.api`，卸载时 delete）。

```ts
window.siyuanCheckin = {
    name: "siyuanCheckin",
    protocol: "siyuan-checkin", version: 5, storeVersion: 2,
    capabilities: [/* 20 项，见下 */],
    capabilitiesSince: { /* 每能力首次出现的协议版本 4|5 */ },
    events: ["checkin:item-created", "checkin:item-updated", "checkin:event-recorded",
             "checkin:event-deleted", "checkin:item-deleted", "checkin:item-archived",
             "checkin:suggestion-workflow-updated", "checkin:analytics-updated"],
    deprecated: [],
    /* 方法面：items.query / events.range.read / occasions.read / occasions.complete /
       summary.read / analytics.read / metrics.read / export.json / export.csv / calendar.read … */
};
```

关键能力（含硬限制，源码常量）：
- `items.query`（v5）：defaultLimit 200，**maxLimit 1000**。
- `events.range.read`（v5）：**maxItemIds 200**、defaultLimit 1000、maxLimit 5000、maxDays 366。
- `events.record`（v4）/`events.record.batch`（v5，maxItems 200）——effect: **write**。
- `occasions.read`（v4，read）/`occasions.complete`（v4，**write**）——均 localOnly。
- 每能力三元组 `{available, localOnly, effect}` 可运行时探测（EC03 的探测源）。

集成事件（window CustomEvent，`checkin:*` 八种）：item/event 的增删改与 analytics 更新——**EC10 的"他端打卡变化 → 管家指标刷新"触发源就是这些事件**（比 ws-main 更精准）。

**对接落点**：EC09 指标绑定 = `items.query`（≤1000）选习惯；EC10 数值承接 = `events.range.read`（≤200 itemIds、≤366 天）+ 监听 `checkin:event-recorded/deleted` 增量；EC11 家务/备考绑定同 EC09；**EC12 生日/纪念日**：`occasions.read/complete` 服务于打卡自身的场合（生日/纪念日类习惯），管家是否写入 occasions 仍需与打卡方确认 owner（EC12 未定案点保持）。

## 3. 雷切 · 注册 API（EC16/EC17/EC19）

来源：`小驴雷切/src/index.ts`（L4753/L4778/L4829）+ `home-model.js`。

```ts
// 动作注册（EC16）：id 限 [A-Za-z0-9._:-]+；返回注销函数；token 防重复注册覆盖
registerQuickAction({
    id: string; label: string; icon?: string; value?: string;
    targets?: QuickActionTarget[];
    handler: (value: string) => void | Promise<void>;
}): () => void

// 家庭摘要模块（EC17）：显式只读边界（"Opt-in read-only module boundary"）
registerHomeModule({
    moduleId: string; title?: string; icon?: string; category?: string;
    supportedDevices?: Array<"desktop" | "sidebar" | "mobile">;
    sizes?: Array<"xs"|"small"|"medium"|"tall"|"wide"|"large"|"full">;
    protocolVersion?: number; author?: string; homepage?: string;
    source?: { pluginId?: string; name?: string; icon?: string; version?: string; homepage?: string; collection?: string; order?: number };
    clickCommand?: string;                    // 点击跳转（管家 Tab 的 siyuan:// 或命令）
    configSchema?: Array<Record<string, unknown>>;
    refreshOn?: Array<"switch-protyle" | "loaded-protyle" | "destroy-protyle">;
    read: (config, device) => unknown | Promise<unknown>;  // 摘要数据钩子
    readOnly?: boolean; open?: () => void;
}): () => void
```

语义与边界（源码确认）：
- `registerQuickAction` 的 id 字符集校验、注册 token（后注册覆盖保护）、返回的 disposer 幂等。
- `registerHomeModule` 的 `read(config, device)` 是雷切向管家拉摘要的钩子——**EC17 的"有界计数"通过它返回**（loading/error/stale 形态按雷切 homeRuntime 的约定，需读 home-model.js 确认返回 shape——下一轮）；`configSchema` 支持用户配置；`readOnly` 显式声明。
- 未注册成功时 disposer 返回 no-op（`registration.registered` 守卫）——重复加载安全。

**对接落点**：EC16 = `registerQuickAction({id: "lvhome.open-reminders", label, handler: () => 管家打开提醒页})`；EC17 = `registerHomeModule({moduleId: "lvhome.summary", read: async () => ({ overdue, soon, updatedAt, complete: boolean }), readOnly: true, clickCommand: 管家命令})`——默认不共享生日/金额（EC17 边界维持）。
