# 思源内核 av 端点调研（2026-10-05，第二百一十六波）

> 动机：R5 附注"非 detached 行绑定待 transactions 端点探索"与写路径稳定性核查。方法：拉取上游 master 的官方 API 文档（2918 行），枚举公开 av 端点全集并与插件用法逐一对账。

## 2. 关键发现

| # | 发现 | 影响 |
|---|---|---|
| F1 | **batchSetAttributeViewBlockAttrs 未入公开文档**——API.md 141 行明示"其余内核路由与 /api/transactions 均为内部实现，无兼容性保证"。插件 setCell 原用此端点 | **已迁移**到文档化的单数 setAttributeViewBlockAttr（itemID 参数与 D02 行 ID 空间一致），活体 IT-02 真机验证通过 |
| F2 | 单数端点的旧参数 `rowID` 2026-12-01 弃除——上游在主动收敛参数命名 | 我们自始用 itemID，零影响 |
| F3 | **render 官方参数文档化**：page/pageSize/query/viewID/createIfNotExist/persistView——E13 的分页结论获官方口径背书；服务端 query 全文过滤可用（暂无用例：台账页搜索已在客户端做且支持备注列） | 记录备用 |
| F4 | **addAttributeViewBlocks 文档化绑定模式**：`srcs[].isDetached:false + srcs[].id(块ID)` 即"把已有文档块收进台账"——**R5 待探索项正式解锁**；另 previousID 可指定插入位置、srcs[].itemID 可显式指定期望行 ID（D02 行确认的候选强化） | 已记 R5 解锁；功能立项另议（"把日记块收进台账"属新入口，克制清单边缘） |
| F5 | searchAttributeView：**跨工作台按名称搜数据库**（返回 avID/viewID/blockID/hPath） | 候选：命令面板"跳转任意台账"；当前 dbRefs 模型下价值有限，观察 |
| F6 | getAttributeViewSearchTarget 有安全公告（GHSA-9cqf-hhrq-7v45，匿名读者可经此泄露行内容）——插件未使用该端点 | 无影响；佐证"内核 API 不对匿名开放"的本地优先原则 |
| F7 | setAttrViewFilters/Sorts/Group/Layout 为**视图配置写端点**——视图属思源 UI 所有权（ADR-4），插件不代写 | 不吸收（与 ADR-4 一致） |
