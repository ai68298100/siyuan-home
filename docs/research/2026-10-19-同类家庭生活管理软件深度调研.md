# 同类家庭与生活管理软件深度调研（2026-10-19）

> 调研目的：梳理当前国内外主流家庭管家、生活管理软件及 GitHub 优秀开源项目（Homechart、Cozi、Grocy、Wallos、Mealie、Notion Family OS），提炼成熟设计模式与核心价值路径，为小驴管家（Lv Home）后续架构演进与功能深化提供输入。

## 二、 核心功能域对比与设计提炼

### 1. 经常性订阅与长期支出管理（参考 Wallos）
- **痛点**：用户往往订阅了大量月付、季付、年付服务（流媒体、云盘、宽带、健身房、软件会员），单笔金额小但累积支出惊人，极易遗忘续费节点。
- **最佳实践**：
  - **周期归一化折算**：不论服务是日付、周付、月付、季付还是年付，一律折算出“月均成本”与“年化总支出”，直观暴露财务漏斗；
  - **自动续约决策链**：在到期日前不仅提醒扣款，更明确提示“是否需要退订”，并提供官方退订引导指引链接（Cancel Guide URL）；
  - **车位与家庭共享角色**：标注自己是主卡人（Holder）还是拼车成员（Member），清晰家庭责任划分。
- **小驴管家落地情况**：已在 `memberships` 模块落地 `calculateSubscriptionStats` 周期折算、年费月化、自动续费占比统计及一键复制分析简报（第二百八十八波）。

### 2. 食品健康与安全屏障（参考 Mealie & Grocy）
- **痛点**：婴幼儿添加辅食需防范过敏风险；多人口家庭做饭时常面临各成员挑食、忌口或严重食物过敏（如坚果、海鲜、乳糖不耐），易发生安全隐患。
- **最佳实践**：
  - **自由文本食材智能分词**：自动将长文本食材（“花生 2两，香菜少许”）清洗为标准词条；
  - **全家忌口安全核查**：录入菜品或制定餐单时，系统自动遍历全家成员的健康过敏档案及个人备注偏好，标出高危过敏（Allergy）与偏好冲突（Dislike）；
  - **3天排敏观察周期**：婴幼儿新食材排敏追踪，实时计算观察期第几天与截止日，并将过敏反应一键归档至健康病历台账。
- **小驴管家落地情况**：已在 `food` 与 `parenting` 模块分别落地食材忌口交叉比对面板、一键生成采购清单与辅食 3 天观察期（第二百八十二波、第二百九十一波）。

### 3. 耐用资产与房产车辆维保（参考 Homechart & Grocy）
- **痛点**：大件家电、数码设备与房屋工程保修期长达数年，一旦发生故障很难快速核对是否在保、保修范围是什么、该联系谁。
- **最佳实践**：
  - **只读跨台账联动**：房屋台账与合同台账不强行合并，而是通过房产名称、签约方与责任成员只读检索关联的装修质保单、租赁合同与物业协议，动态计算剩余保修天数；
  - **购物转资产一键归档**：在购物记录收到耐用品后，一键提取名称、金额、渠道、日期与附件转存入实物资产台账，避免二次繁琐录入；
  - **资产净值与折旧监控**：通过 rowlog 记录不同年份的手动估值，计算资产现值变动与高价值资产排行。
- **小驴管家落地情况**：已在 `house` 与 `shopping` 模块落地房屋维保联动核对、购物转资产建档与资产估值汇总（第二百八十一波、第二百八十九波）。

### 4. 宠物照护与生命周期（参考 Barney & PetDesk）
- **痛点**：猫犬等宠物的生理年龄与人类不同，各生命周期阶段（幼年、成年、老年、高龄）的营养和医疗需求差异极大，且狂犬联苗与体内外驱虫周期各不相同。
- **最佳实践**：
  - 依据 AAHA / AAFP 权威兽医模型，将宠物出生年月换算为人类对等年龄与阶段判定；
  - 实时评估疫苗与驱虫状态（已按期/临期/逾期），给出阶段性照护指引。
- **小驴管家落地情况**：已在 `pets` 模块落地 `calculatePetAge` 生理年龄换算与护理周期追踪（第二百九十四波）。

## 三、 小驴管家（Lv Home）的差异化竞争优势

相较于上述商业或自托管开源产品，小驴管家具备独特的架构护城河：
1. **真正的本地优先（Local-first）**：数据存放在用户自己的思源笔记原生属性视图与文档中，不依赖 Docker 部署，不依赖第三方云端中继，断网完全可用；
2. **免维护与零运维负担**：无需像 Grocy 或 Wallos 那样维护 MySQL/PHP 环境与数据库备份，思源的同步机制会自然带着台账走；
3. **数据绝不锁定**：所有数据可在思源原生数据库中双向编辑，随手嵌入日常笔记或日记，随时导出标准 CSV、.vcf、.ics 与 JSON；
4. **单文件单源打包**：遵循严格的思源加载器兼容规范，在保持轻量（0.5MB+）的同时，单测达到 500+ 项，具备极高工程健壮性。

## 四、 丰富后的后续待办规划建议

结合本次调研，为 `TODO.md` 注入以下下一阶段高阶特性候选：

1. **家庭周餐单与食材缺口自动转采购（Cozi / Mealie 印证）**：
   在 `food` 模块中支持挑选 3-7 道菜组成周餐单，汇总所需食材，自动扣减 `stock` 囤货台账已有数量，一键将缺口食材存入 `shopping` 待购清单。
2. **多设备家庭协作的只读访客模式（Homechart 印证）**：
   研究家庭成员中老人/儿童共用设备时，如何提供仅查看指定生活台账（如药箱、日历、紧急联系卡）而隐藏财务/合同等敏感字段的安全展示模式。
3. **重要证件与合同的换签预警时间线（Notion Family OS 印证）**：
   在家庭成员卡片中聚合显示该成员名下的全部证件效期轴与合同履约状态，形成完整个人数字资产档案。
