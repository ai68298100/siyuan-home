# 小驴管家（Lv Home）项目状态与代码质量审计

> 审计日期：2026-10-07（Asia/Shanghai）
> 审计范围：当前工作区源码、测试、构建与发布脚本、UI 样式、项目文档。
> 说明：本报告记录当前状态、风险和本轮已落地的修复；真实思源宿主、Android WebView、独立窗口和兄弟插件联调仍需按真机批执行。

## 1. 结论先行

项目已从“功能骨架”进入“发布信任和真实使用验收”阶段。当前代码基线是 **v0.3.10**，核心能力和自动化质量较扎实；主要工作已经从继续增加 schema 转为：

1. 关闭移动端、侧栏窄容器、无障碍和生命周期缺陷；
2. 完成真实思源桌面/Android/独立窗口/兄弟插件/双端冲突验收；
3. 清理版本与测试数字的文档漂移；
4. 补运行态损坏恢复和桥接/异常路径测试；
5. 再决定是否解除 `disabledInPublish=true` 并进入集市分发。

当前不建议把“31 个模块”表述成 31 个完整业务模块。更准确的能力层次是：31 个 schema 已覆盖，部分模块已建库、读写和提醒验证，其余模块仍需按 capability matrix 逐项确认。

## 2. 当前已开发情况

### 已落地的生产骨架

- `src/core/schema.ts`：31 个模块的 schema 目录、列类型白名单和契约校验；
- `src/core/provisioner.ts`：按需建库、幂等补列、缺库找回/重建；
- `src/core/hub/`：提醒规则、provider 注册、扫描、运行态、动作、通知、分组展示；
- `src/panels/`：总览、提醒、台账、成员四个生产 Tab，以及设置、首次引导、日历和错误边界；
- `src/index.ts`：顶栏/命令/状态栏/块菜单入口、30 分钟扫描心跳、可见性与 websocket 补扫、移动端入口、生态桥；
- 导入导出与诊断：CSV、ICS、VCF、设置 JSON、脱敏诊断、示例数据、恢复与升级演练；
- 生态能力：人脉、打卡、雷切、考试等桥接代码已存在，但部分仍标记为待实测，不能等同于完成互测。

### 已有证据

- `docs/capability-matrix.md`：31/31 schema 覆盖、22 个提醒块、provider 缺失 0、31 个 capture；8 个启用模块已有真实内核读写行列数；
- `CHANGELOG.md` v0.3.10：记录了依赖升级、GitHub 治理、smoke 安全修复和真实宿主验收边界；v0.3.9 保留 UI 功能变更历史；
- `scripts/e2e-value01.mjs`、`scripts/e2e-recovery.mjs`、`scripts/e2e-import.mjs`：首条价值和恢复路径已形成可重复脚本；
- `docs/testing/device-batch-runbook.md`：六阶段真机批流程已编排，但残余设备项尚未全部关闭。

## 4. UI/交互状态

本轮已关闭此前可直接修复的 P1 问题：设置页支持窄容器换行，Tab 具备完整 tablist/tabpanel 语义和方向键，ledger/member 支持 Enter/Space，移动延时回调统一纳入卸载清理，Dialog 挂载增加空节点保护，`captureTo` 会在建行前校验目标列，错误边界、引导和日历补齐了本地化与 ARIA 语义；桥接扫描未就绪时返回空快照，续期日期校验和内核写回失败路径也已收口。

- Android 软键盘、返回键、旋转、安全区、后台唤醒、长列表和低端设备性能；

- 触控目标命中率、成员卡触摸操作可发现性、焦点循环和读屏行为；
- `100dvh`、嵌套滚动容器和 `scrollIntoView` 在宿主 Dialog 中的实际表现。
