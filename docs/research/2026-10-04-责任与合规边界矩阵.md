# 责任与合规边界矩阵（UG12 · 2026-10-04 第八十五波循环 B）

> UG12 定义（TODO 62 组）：按健康、证件、财务、照护、教育和出行标注后果等级、同意、免责声明、政策有效期和人工核对出口；分享默认最小字段。
> 性质：**研究记录**，不是开发承诺；缺口按证据门禁决定是否立项。

## 基线（已实现的责任边界，本矩阵的地板）

来源：docs/privacy.md、README「明确不做」、代码与第八十–八十四波实测。

1. **数据不出本机**：无网络权限、无遥测、无服务器；台账在思源库、设置在插件存储。
2. **敏感字段脱敏**：证件号仅录后四位；密码类只存"存放位置索引"文字。
3. **通知最小暴露**：提醒标题只到"N 件事"级摘要，不播报证件名/金额。
4. **医疗边界已声明**：生长图 WHO 参考带图注含 © WHO CC BY-NC 3.0 署名 + "仅供家庭参考，不构成医疗建议；咨询专业医师"（第八十波）。
5. **角色边界已声明**：README「明确不做」——不替代记账/密码库/实时接口/问诊/自动办理；插件只整理、派生提醒、留依据、协助准备。
6. **政策有效期机制**：privacy.md 随版本维护，实质变更走 CHANGELOG。
7. **人工核对出口**：提醒为派生提示（延后/忽略/完成皆可），外部办理由用户与机构完成。

## 缺口研判（G = gap，按证据门禁决定去向）

**G1 · 导出分级警示**：CSV/JSON 是最大数据出口，健康/证件/财务与普通生活数据同一出口、同一句"妥善保管"。privacy.md 的导出段只有一句提示。
→ **立项候选（🟢 已登记）**：导出前若所选模块含高后果类别（health/parenting/certs/insurance/assets），确认框点名类别；这是纯本地 UI 改动，无网络面。
**G2 · 模板生成文档的落点说明**：家长会/体检模板把台账字段写入思源文档（进同步/分享范围）。生成按钮的确认框是否说明落点，§7.7 UI 走查项未验证。
→ 并入既有 UI 走查清单（不新增开发），走查时若确认框缺失再立项。

## 结论

- 已实现边界（基线 7 条）覆盖了 UG12 要求的"后果等级、同意、免责、政策有效期、人工核对出口"五要素的**声明面**；
- 唯一实质缺口是**导出分级警示**（G1，已立项候选），G2 并入既有走查；
- 插件不新增任何分享面（无网络、无外发），"分享默认最小字段"在插件层等于"不分享"，文档级分享的权限归思源平台——与 README 声明一致。
- UG12 研究项本身就此闭环；G1 开发完成前，privacy.md 的导出段措辞已如实覆盖现状（"妥善保管"），无声明与实现不一致之处。
