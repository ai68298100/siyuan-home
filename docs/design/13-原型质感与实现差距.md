# 13 · 原型质感与实现差距

> 本文记录 UI 原型从“好看”走向“可实现、可验证、可长期使用”所需的补充工作。原型可以使用合成资料和目标状态，但生产页面必须通过源码、宿主尺寸、主题、键盘/触屏和真实数据回归后才能标记完成。

## 1. 质感的来源

小驴管家的质感来自四件事：

1. **层次有秩序**：画布、工作台、区块、可点击卡片和弹层有清楚的层级；阴影和辉光只帮助分层，不承担信息表达。
2. **信息有口径**：提醒、统计、趋势条、成员进度和附件都带范围、来源、更新时间和完整性；演示数据和真实数据不能混写。
3. **动作有回执**：完成、延后、续期、保存、生成、导出和关闭分别有进行中、成功、部分成功、失败和未知结果。
4. **细节可重复**：图标、文字层级、按钮命中区、焦点、抽屉、主题和移动端布局在不同页面使用同一套规则。

原型当前已经有沉静底色、细线、状态色轨、模块色砖、趋势条、抽屉和弹层等视觉基础。下一步的重点是让这些装饰和真实任务、状态和证据绑定，避免只增加渐变、阴影或动画。

## 2. 本轮原型调整

`prototype/index.html` 已增加：

- 当前范围、数据快照、演示资料状态条；
- “今日处理 / 待确认 / 数据状态”三张工作重点卡；
- 模块卡最低高度、环境光层和更稳定的悬浮层次；
- 键盘聚焦时显示提醒操作，演示动作显示“未写入业务数据”的反馈；
- reduced-motion、forced-colors、触屏和窄屏下的降级规则；
- 抽屉/弹层打开时保存触发焦点，关闭后恢复触发点；
- 原型中补齐最高层关闭、焦点循环、背景不可操作和隐藏弹层语义；快速录入保存仅显示模拟回执，不创建业务记录；
- 原型导航的 `aria-current`、页面标题和状态播报。

这些调整仍属于演示层。它们没有接通生产数据，也不能证明生产组件已经具备同样行为。

## 3. 原型到生产的关键差距

### 3.1 宿主容器与滚动

原型以浏览器窗口和 `window.scrollTo` 为基准，生产页面运行在思源 Tab、窄侧栏、独立窗口和移动 WebView 中，滚动所有权可能属于面板、列表、抽屉或弹层。必须按宿主的 `clientWidth/clientHeight` 决定抽屉宽度、弹层最大高度、背景锁定和内部滚动，关闭详情后恢复原筛选、滚动锚点和焦点。

### 3.2 图层与焦点

蒙层、抽屉、快速录入、确认框和错误面板需要统一状态机。抽屉打开后再打开弹层，按 Esc、点蒙层、浏览器返回或销毁组件时，都应只关闭当前最高层并恢复前一层。键盘焦点需要初始落点、循环范围、`aria-modal`、背景不可操作、错误聚焦和关闭后恢复。

### 3.3 操作可见性

原型中提醒操作在 hover 时浮现，生产必须同时支持 `focus-within`、触屏、触控笔和窄屏详情入口。完成、延后、定位、关闭等关键动作不能只有 32px 图标命中区，也不能只依赖颜色或 title 属性。按钮的文案、图标和结果状态需要跨总览、提醒、成员和详情保持一致。

### 3.4 数据真实性

原型的 4 条提醒、模块计数、64% 进度、金额、附件和健康状态都是合成资料。生产每个数字都要能说明统计范围、单位、来源、更新时间和读取完整性。provider 未接入、扫描失败、权限不足或快照陈旧时，不显示 0、绿色健康或“全部完成”。

### 3.5 事实、草稿和 AI

生产页面要把正式事实、用户输入、AI 草稿、建议、待核对和未知结果分成不同视觉层。AI 字段旁需要来源定位、形成日、核对日、目标版本和采用动作；未确认的草稿不能进入提醒、统计或成员档案。AI 关闭后，手工路径仍要完成核心查看、录入、提醒处理和导出。

### 3.6 统计和动效

趋势条、进度条和数字滚动需要说明公式、时间范围、样本量、缺测和更新时间；缺测不能补零。图形必须有文本或表格替代，减弱动效后不能丢失状态。动效预算应覆盖首次加载、切 Tab、长列表滚动、抽屉开关和低端设备。

## 6. 本轮原型验证范围

2026-10-02，通过本地 HTTP 服务和 Playwright 浏览器检查了七个原型页面在 1440px、375px 宽度下的导航、页面标题和当前导航状态，页面均未发生横向溢出。375px 下四条提醒的操作按钮常显，按钮高度为 44px。另核对了明暗主题、系统强制颜色模拟、减弱动效后的计数、模拟保存回执、焦点循环、嵌套层只关闭最高层及关闭后恢复触发焦点。

这批证据仅验证浏览器中的合成演示。思源 Tab、独立窗口、移动 WebView、真实读屏、实际对比度和生产数据仍按 PL 矩阵验收，所有新增规划项保持未完成；原型的筛选样式和模拟保存不代表业务链路已实现。

v4 追加 320px 场景回归、模块草稿隔离、记录身份、组合筛选和 AT05 合成解释的验证；修正长期有效/未登记语义、部分失败数量说明、回执焦点及表格滚动。28 项合成检查通过，另有 3 类流程未模拟，逐项结果、截图与后续主责见 [场景原型与 AI 协作验证](./14-场景原型与AI协作验证.md)。本轮将缺口归入现有 H/F/OP/PP/AX/PL 待办，不新建功能组或把原型结果换算为生产完成率。
