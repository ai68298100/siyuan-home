# 08 · UI 组件库与实现规范（组件契约）

> 本文是 C1-C8 开发的**组件契约**：每个界面元素在此有唯一类名、变体与使用位置。
> 视觉基准：[prototype/index.html](../../prototype/index.html)「组件库」屏（活体样式指南）；token 定义见 [07 视觉设计语言](./07-视觉设计语言.md)。
> 可编译实现：`src/styles/design-system.scss`（已通过构建，作用域 `.lv-home`，颜色全部 b3 变量派生）。

---

## 1. 命名与作用域规则

1. **作用域**：一切自有类嵌套于 `.lv-home`（插件容器）内，不污染主界面；类名前缀 `lv-`。
2. **命名**：`lv-<组件>` + 修饰符后缀（`primary/ghost/sm/on/open/sel/overdue/soon/lead`…）；布局工具类沿用 `.fn__flex` 等 b3 工具类。
3. **b3 优先原则**：表单原语（输入框/下拉/开关/复选）与思源原生 UI 并列处，优先 `b3-text-field / b3-select / b3-switch / b3-button`；`lv-*` 自有类用于复合组件与设计系统独有元件。两者 token 一致，可混用。
4. **图层**：面板内 z-index —— topbar 50 / mask 90 / drawer 100 / modal 110（token：`--lv-z-*`）。Toast 一律用思源 `showMessage`，不自建。

## 2. Token（实现形态）

`.lv-home` 上定义 CSS 自定义属性，**无 b3 对应的由 b3 变量 color-mix 派生**（自动跟随明暗与用户主题）：

| 组 | token |
|---|---|
| 强调 | `--lv-accent`(=primary) `--lv-accent-soft`(14%) `--lv-accent-line`(32%) |
| 面/线/字 | `--lv-surface-2` `--lv-line` `--lv-line-strong`(14% on-background) `--lv-tx/-2/-3` |
| 状态 | `--lv-danger/-soft` `--lv-warn/-soft` `--lv-amber/-soft`(warn 派生) `--lv-ok/-soft` |
| 材质 | `--lv-inset`(内高光) `--lv-aura`(环境辉光) |
| 动效 | `--lv-ease` `--lv-spring` `--lv-t-fast/med/slow/sheet`(120/180/240/320ms) |
| 几何 | `--lv-r-1/2/3/4`(6/10/14/18px) `--lv-z-*` |
| 阴影 | `--lv-shadow-1/2/3` |

> 颗粒纹理（`--lv-noise`）仅存在于原型：插件面板为滚动容器，全屏颗粒成本>收益，暂不实现（Tab 全高容器若需可加 `--page` 修饰符，见 §7）。

## 5. 布局系统

- Tab 面板：`max-width 1160px` 居中（`.app`），内边距 28px（移动 16px）；设置页 `190px + 1fr` 双栏（移动单栏，导航横向滚动）。
- 节奏：区块间 26px（`.lv-sec` 自带 margin），卡片内 16-20px，4px 基数。
- 断点：`760px` —— 页标题缩至 21px、`.lv-rem-ops` 隐藏（移动端靠抽屉内操作）、设置变单栏。
- 台账页是例外：外层 `.lv-ledger-shell` + 嵌入的原生数据库视图（S1 定案），自有样式只包外壳。

## 6. 动效实现清单（与 07 §5 一一对应）

1. 屏幕切换/入场编排：`.lv-anim.lv-screen` nth-child 延迟（已在 design-system.scss）。
2. 导航胶囊：JS 计算 `offsetLeft/offsetWidth`，`--lv-spring` 过渡。
3. 微反馈：卡片 `-2px` + 砖 `scale(1.08) rotate(-4deg)`；按钮按压 `translateY(1px)`。
4. 抽屉/弹层：`translateX(36px)→0 / translateY(16px) scale(.97)→none`，spring 320ms。
5. 呼吸点：`.pulse::after` 3.4s 光环扩散（唯一常驻）。
6. 数字滚动：总览计数 560ms ease-out-cubic（JS，仅一处）。
7. `@media (prefers-reduced-motion: reduce)` 全关（已内置）。
