# 02 · 数据模型与模块规格

> 自上而下设计 · 第三层（L3）。前置阅读：[01 架构总览](./01-架构总览.md)。
> 原则：台账全部落思源数据库（行=块）；本文定义**字段字典**（标准列）、**成员库**、**31 个模块的 schema** 与**建库器**规格。

---

## 1. 实体关系

```
                    ┌────────────────────┐
                    │  成员库 members     │  ← 一张数据库，每行=一个成员(块)
                    │  (全局关系枢纽)      │
                    └─────────┬──────────┘
                              │ 关系列 "member"
        ┌──────────┬──────────┼──────────┬──────────┐
        ▼          ▼          ▼          ▼          ▼
   ┌─────────┐┌─────────┐┌─────────┐┌─────────┐┌─────────┐
   │ 证件certs││ 药箱med. ││ 保单ins. ││ 上学sch. ││ …各模块  │   每模块一张数据库
   └────┬────┘└─────────┘└─────────┘└─────────┘└────┬────┘
        │ 行=块，可被任意文档双链引用                     │
        ▼                                             ▼
   ┌────────────────────────────┐        ┌──────────────────────┐
   │ 文档（长内容）：说明书/游记/  │        │ 附件：扫描件/发票/PDF  │
   │ 菜谱/应急预案 …（模板生成）    │◄──────►│ 挂在台账行的资产字段    │
   └────────────────────────────┘        └──────────────────────┘
```

- 跨模块引用（如"装修合同 ↔ 维修记录"）用关系列或块引用，不复制数据。
- 家庭级模块（房屋、订阅）成员列留空 = 全家共有。

## 2. 字段字典（标准列）

所有模块 schema **只允许两类列**：字典标准列 + 模块私有列（前缀 `x_`，尽量少用）。保证跨模块查询、统计、导出一致。

| key | 类型 | 说明 |
|---|---|---|
| `name` | text | 主名称（首列） |
| `member` | relation→members | 归属成员；空=全家 |
| `category` | select | 模块内分类（枚举见各模块） |
| `status` | select | 状态机（见 §5） |
| `date` | date | 业务日期（购买日/就诊日/起始日） |
| `expiry` | date | 到期日/效期（提醒中枢扫描对象） |
| `remind_before` | number | 提前提醒天数（覆盖模块默认值） |
| `amount` | number | 金额 |
| `currency` | select | 币种（默认 CNY） |
| `cycle` | select | 周期（用于周期账/周期任务：month/quarter/year/n 年） |
| `location` | text | 物理位置（房间→柜）或地址 |
| `attachments` | assets | 扫描件/照片/发票/PDF |
| `url` | text | 相关链接（商品/网站/地图） |
| `tags` | m-select | 自由标签 |
| `note` | text | 备注 |
| `due` | date | 下次到期/下次发生日（周期规则的计算结果，由中枢写回） |

## 3. 成员库 `members`（全局枢纽，alwaysOn）

| 列 | 类型 | 说明 |
|---|---|---|
| name | text | 称呼 |
| role | select | self/spouse/partner/child/elder/kin/other |
| birthday | date | 公历生日 |
| lunar | checkbox | 生日按农历 |
| relation_note | text | 关系说明（如"我母亲"） |
| size_top / size_bottom / size_shoe | text | 尺码档案（购物礼赠场景） |
| dislike | text | 忌口/过敏摘要（联动餐饮与健康） |
| avatar | assets | 头像 |
| status | select | active / archived（去世、疏于往来时归档不删） |
| note | text | 备注 |

## 4. 模块 Schema 规格

### 4.1 ModuleSchema 接口（代码形态）

```ts
interface ModuleSchema {
    database: { nameKey: string };            // i18n 键，如 "module.certs"
    columns: ColumnDef[];                     // 字段字典引用 + 私有列
    capture?: string[];                       // 快速录入表单的列集（≤5，按序），缺省 = 前 4 个 required 列
    views?: ViewDef[];                        // 默认视图（建库时创建）
    templates?: { key: string; docName: string }[];  // 长内容文档模板
    reminders?: ReminderRuleSpec[];           // 声明哪些列参与提醒中枢（见 03）
}
interface ColumnDef { key: string; type: ColumnType; labelKey: string;
                     options?: string[]; required?: boolean; }
```

**capture 列集**（快速录入对话框与块菜单预填共用，见 04 §5）：

| 模块 | capture 列序 |
|---|---|
| certs | name, member, category, expiry, attachments |
| assets-real | name, category, price, purchase_date, attachments |
| medicine | name, category, expiry, stock_qty, location |
| memberships | name, category, amount, cycle, next_billing |
| shopping | name, amount, channel, date, tracking_no |
| favors | direction, event, person, amount, date |
| media | name, type, status, rating |
| stock | name, qty, low_stock_at, expiry |
| schooling | name, school, category, tuition, next_pay_date |
| snippets / address / bookmarks | name + content/url/location（入口多来自块菜单预填） |

**Provisioning（建库器）流程**：模块被启用 → 检查目标笔记本（默认"🏠 小驴管家"，无则创建）→ 按模板新建模块文档（内含一张空数据库，列按 schema）→ 创建默认视图 → 在 settings 记录 `moduleId → docId/avId` 映射 → 幂等（已存在则跳过/补列）。模块禁用 → 只移除 UI 与提醒，数据保留。

### 4.2 核心模块 schema（8 个，v0.2–v0.4 交付）

**① certs 证件管理** — 单一证件台账，`category` 选择类型 profile；旧 `permit`/`license` 值保留兼容，新增港澳/台湾通行证、驾驶证、职业/从业资格证、毕业证、学位证、职称证。
| 列 | 说明 |
|---|---|
| name / member / category / status | 有效期中 / 已过期 / 已换新 / 已注销 |
| holder_no | 证件号**后四位**（脱敏，绝不存全号） |
| issue_date / expiry | 签发日 / 到期日 |
| remind_before | 默认提前 90 天；按行可覆盖 |
| issuance_rules | select：6年/10年/长期/签注另计（驾驶证与通行证签注规则） |
| location | 实物存放位置 |
| attachments | 通用附件；类型 profile 追加 `x_cert_` 字段（学校/专业/发证机关/准驾车型等）和独立 mAsset 扫描件列 |

快速录入根据 category 只显示对应 profile 字段。图片/PDF 可在快速表单中选择或调用手机相机，上传失败保留待重试；详情中的附件提供同源预览和下载按钮。完整证件号不入库，建议只记录后四位。

**② assets-real 实物资产** — `category`: 家电/家具/数码/玩具/衣物/首饰/收藏/运动器材/图书/其他
| 列 | 说明 |
|---|---|
| name / member / category / status | 在用 / 闲置 / 借出 / 维修中 / 已处置 |
| qty, price, purchase_date, purchase_channel | 数量、价格、购买日、渠道 |
| warranty_expiry | 保修截止（→提醒） |
| location | 位置层级：房间/区域→柜/箱 |
| brand_model, sn | 品牌型号、序列号 |
| lend_to, lend_date | 借给谁、何时（借出状态用） |
| dispose | 处置记录（卖价/平台/日期） |
| attachments, tags | 发票、照片 |

**③ medicine 家庭药箱** — `category`: 处方药/OTC/外用药/器械/保健品
| 列 | 说明 |
|---|---|
| name / member / category / status | 在用 / 备用 / 已过期 / 已丢弃 |
| expiry, stock_qty, stock_unit | 效期（→提醒）、余量+单位 |
| low_stock_at | 余量阈值（低于触发提醒，默认 1） |
| indication, dosage | 适应症、用法用量 |
| location | 药箱位置 |

**④ memberships 会员与订阅** — `category`: 会员卡/储值卡/订阅服务/优惠券/积分
| 列 | 说明 |
|---|---|
| name / member / category / status | 使用中 / 已过期 / 已退卡 |
| expiry, cycle | 到期日、计费周期（月/季/年） |
| next_billing, trial_end | 下次续费日（→提醒）、试用期截止（→提醒） |
| amount, prepaid_balance | 费用、储值余额 |
| auto_renew | checkbox 自动续费（ true 时试用期提前 3 天提醒取消） |
| credentials_note | 账号名/卡号后四位（不存密码） |

**⑤ health 病历与健康** — `category`: 就诊/检查报告/疫苗/用药史/过敏/体检
| 列 | 说明 |
|---|---|
| name / member / category / status | 跟进中 / 已结案 |
| date, hospital, department | 就诊日、医院、科室 |
| diagnosis, prescription | 诊断摘要、处方 |
| followup_date | 复查/复诊日（→提醒） |
| attachments | 报告、化验单照片 |

**⑥ insurance 保险** — `category`: 医疗险/重疾/意外/寿险/车险/财产险/其他
| 列 | 说明 |
|---|---|
| name / member / category / status | 生效 / 缴费期 / 已到期 / 已退保 |
| insurer, policy_no | 公司、保单号 |
| premium, pay_cycle, next_pay | 保费、缴费周期、下次缴费日（→提醒） |
| coverage, expiry | 保额、保障到期（→提醒） |
| beneficiary | 受益人 |
| attachments | 电子保单 PDF |

**⑦ social 社保医保** — `category`: 社保/公积金/医保/居民养老/商业养老
| 列 | 说明 |
|---|---|
| name / member / category | 账户档案 |
| account_no | 账号后四位 |
| retire_check | checkbox 计入退休倒计时 |
| retire_age | 法定退休年龄（默认按政策参数，可改） |
| balance_snapshot, snapshot_date | 余额快照、快照日期（手动更新，不做对接） |

**⑧ schooling 上学管理** — `category`: 幼儿园/小学/初中/高中/大学/研究生/课外班
| 列 | 说明 |

| name / member / category / status | 在读 / 已毕业 / 择校中 |
| school, grade, class, teacher | 学校、年级、班级、班主任 |
| enroll_year, graduate_year | 入学/毕业年份（推算当前年级） |

## 5. 状态机（status 枚举汇总）

- **通用**：active → archived（归档不删，保留历史与提醒静默）
- assets-real：在用 → 闲置 / 借出 / 维修中 → 已处置（终态）
- media：想看/想读 → 在看/在读 → 看完/读完（可 → 弃）
- schooling：择校中 → 在读 → 已毕业
- insurance / memberships：生效/使用中 → 到期 → 续期(回到生效) / 退保/退卡（终态）
- 周期类（chores/stock/house 缴费）：由中枢写回 `due`，无人工状态

## 6. 数据迁移与兼容

- 建库器**幂等**：启用已启用模块 = 跳过；版本升级新增列 = 自动补列（不删不改旧列）。
- 台账升级只增不改：字段字典列 key 一旦发布即冻结，废弃列保留但 UI 隐藏。
- 插件卸载：思源数据库与文档留存；settings 删除。重装后 provisioner 按 docId 映射找回。

## 7. 模块间引用图谱（联动数据的落点）

跨模块关系一律用**关系列或块引用**存 ID，缺失时降级显示名称快照（与 05 §2.3 同一策略）：

```
certs ──────────► members（成员）
travel-packing ──► certs        行前清单"证件自查"引用证件库条目状态
shopping ────────► assets-real  linked_asset：购入一键转资产
shopping ────────► memberships  用哪张会员卡/储值卡支付
contracts ───────► house        装修合同 ↔ 房屋维护（保修期内报修）
contracts ───────► members      对方联系方式（进一步→人脉联系人）
schooling ───────► exams        孩子考级/等级考试同源
schooling ───────► members      teacher/班主任（→人脉）
allowance ───────► members      kid_account：按孩子分账
parenting ───────► health       辅食新食材观察 → 过敏史
health ──────────► medicine     处方用药 → 药箱存量核对
food ────────────► members      忌口标签（成员库 dislike）
travel-log ──────► travel-plan / travel-booking  日记/花费挂在行程下
assets-real ─────► members      借出对象 lend_to
house ───────────► members      缴费户号/纪念日归属
```

规则：① 只允许"业务上拥有"的一方持有引用（如购物拥有"转出的资产"，资产不知购物）；② 引用计数不做、删除被引用方时提示但允许；③ 引图谱随模块增长维护在本节，作为跨模块查询/统计的实现依据。
