# 04 · 交互与 UI 原型

> 自上而下设计 · 第五层（L5）。所有 UI 复用 b3 组件与 CSS 变量，跟随思源明暗主题。
> **本文线框图定义信息架构与交互**；视觉与动效的最终标准见 [07 视觉设计语言](./07-视觉设计语言.md) 与其配套高保真原型 [prototype/index.html](../../prototype/index.html)——实现阶段以原型为准。
> 前置阅读：[01 信息架构](./01-架构总览.md) · [03 提醒中枢](./03-提醒中枢.md)。

## 1. 全局入口矩阵

| 入口 | 形式 | 到达 |
|---|---|---|
| 顶栏 🏠 按钮 | 图标按钮（桌面+移动） | 管家 Tab（总览页） |
| 命令面板 | `打开管家面板`（可设快捷键） | 同上 |
| 顶栏 ⚡ 快速记录 | 图标按钮 | 快速录入对话框 |
| 斜杠命令 | `/lv` → 快速记录 / 打开台账 / 存为常用语 | 对应入口 |
| 块菜单右键 | 选中文字 → `存为常用语 / 存为网址 / 存为地址` | 预填的快速录入 |
| 块图标菜单 | 台账块（数据库）→ `在管家面板打开` | 台账页定位到该模块 |
| 设置 | Tab 内 ⚙ / 设置面板插件项 | 设置 Dialog |

## 9. 移动端适配

- Tab 结构保留（思源移动端支持自定义 Tab）；总览单列布局，模块卡两列网格。
- 快速录入悬浮于顶栏 ⚡；块菜单入口不可用（移动端无块菜单），由斜杠与顶栏替代。
- 提醒：无桌面通知 → Tab 角标 + 打开面板刷新；摘要通知依赖思源自带推送（无则降级为角标）。
- 台账视图：原生数据库移动端只读为主，编辑引导回桌面端（文案提示）。

## 10. 可用性规范

| 场景 | 规范 |
|---|---|
| 空状态 | 每个视图给"下一步动作"型空态（如成员空→"先添加自己"），不放装饰性空图 |
| 危险操作 | 删除成员/禁用模块（含数据时）/删台账行 → 确认对话框，文案说明数据去向（归档不删优先） |
| 加载 | 台账嵌入视图骨架屏；提醒列表本地缓存优先渲染再刷新（不闪白） |
| 错误 | toast（3s）；批量失败聚合到设置·关于·诊断，不打断主流程 |
| 快捷键 | `打开管家面板` 可配置；`快速记录` 可配置；不做更多全局键避免冲突 |
| 可达性 | 全部交互元素可键盘到达（焦点态用 b3 原生焦点样式）；图标按钮带 title/aria-label；颜色分级 🔴🟠🟡 同时有文字级别冗余，不单靠颜色传义 |
| 文案 | 全部走 i18n；金额/日期本地化格式；证件号等敏感字段默认脱敏显示，点击可见 |
