## 2. 小驴生态 API（互通协议）

**原则**：插件间不直接读对方数据，全部走显式 RPC + 用户开关（设置·生态）。承载：思源 3.8.x kernel.js 的 `rpc.bind` + broadcast；前端间经 `siyuan` 事件总线兜底。

### 2.1 本插件对外提供（server = 小驴管家）

| 方法 | 签名 | 用途（调用方） |
|---|---|---|
| `home.getSnippets` | `() -> {id,name,content}[]` | 快切：常用语面板（需开启） |
| `home.getBookmarks` | `(category?) -> {id,name,url,account_note}[]` | 快切：网址面板 |
| `home.recordValue` | `(memberId, metric, value, date?) -> void` | 打卡：体重/身高/油耗等数值落育儿/车辆/健康台账 |
| `home.getMemberBirthdays` | `() -> {memberId,name,date,lunar}[]` | 人脉/打卡：农历生日提醒复用 |
| `home.linkContact` | `(memberId, contactRef) -> void` | 人脉：成员↔联系人双向引用 |
| `home.archiveRef` | `(moduleId, blockId, sourceRef) -> void` | 拾遗：剪藏一键归档为台账行附件/关联文档 |

### 2.2 本插件消费（client）

| 提供方 | 方法 | 用途 |
|---|---|---|
| 人脉 | `contacts.search(name)` | 台账中"对方联系方式"（合同/保险/学校老师）联想 |
| 打卡 | `habits.list()` | 家务/备考等台账任务一键转打卡习惯 |
| 快切 | 面板注册 | 管家 Tab 卡片加入快切切换列表 |

### 2.3 兼容策略

- 每个方法带 `since` 版本号；调用前 capability 协商（`home.capabilities`）。
- 对方插件未安装/未开启开关 → 功能静默隐藏，不报错不降级文案污染。
- 引用只存 ID + 名称快照，对方缺失时显示快照（不产生断链红字）。

## 3. kernel.js 服务规划（L4 常驻层）

| 能力 | 设计 | 版本 |
|---|---|---|
| 定时扫描 | 每日 08:00（可配）全量提醒扫描，结果写 kernel storage，broadcast `hub.updated` | v0.2 |

## 4. 隐私与安全设计

1. **脱敏**：证件号/账号/卡号字段一律后四位；设置可开"面板隐藏金额"（人情/资产场景）。
2. **无密码**：任何模块不提供密码字段；虚拟资产只有"密码存放位置索引"（指向 1Password/Bitwarden 条目名）。
3. **附件即文件**：扫描件为思源附件（本地 assets），不外传；同步加密依赖思源自建加密同步。
4. **通知脱敏**：桌面通知标题用"3 条家庭事项到期"，不播报具体证件名（可关）。
5. **导出提示**：CSV/JSON 导出前提示包含敏感字段，默认导出脱敏版。
6. **无遥测**：不采集、不上报任何使用数据；问题诊断只依赖本地日志与设置页诊断区。

## 4.5 性能预算

| 指标 | 预算 | 手段 |
|---|---|---|
| 插件 onload | 不做任何同步内核调用；< 50ms（只读设置与注册） | 设置异步加载；Tab 懒建 |
| 提醒全量扫描（31 模块） | < 50ms | 范围 SQL（日期列）；kernel storage 缓存 |
| 管家 Tab 首开 | < 150ms（缓存渲染先行，刷新静默替换） | HubState 缓存 + 骨架屏 |
| 成员下钻聚合 | < 100ms | 关系列查询；无 N+1 |
| 构建产物 | index.js gzip < 100KB；农历库 tree-shake 后 < 30KB | 无 UI 库依赖，纯 b3 |
| 内存 | 常驻 < 20MB | 无轮询定时器（kernel 触发为主） |
