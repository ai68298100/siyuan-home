# 07 · 视觉设计语言（v1）

> 配套可交互原型：[prototype/index.html](../../prototype/index.html)（浏览器直接打开，右上角可切换明暗主题，七屏可点击切换，含「组件库」活体样式指南）。
> 本文档回答三件事：原型遵循什么理念、每个 token 如何映射回思源 b3 变量、实现时哪些规则不可破。
> 交互与信息结构见 [04 交互与UI原型](./04-交互与UI原型.md)；本文只管"看起来与动起来"。
> **实现契约**见 [08 UI组件库与实现规范](./08-UI组件库与实现规范.md)（类名/变体/使用位置）与 `src/styles/design-system.scss`（可编译实现）。

## 1. 设计命题（Visual Thesis）

**「沉静的精密仪表台」** —— 一个值得托付全家重要日期的界面，应该像一台校准过的仪器：底色沉稳、层次用微光区分、数据用等宽字对齐、唯一的强调色只给"需要注意的事"。

- **情绪**：沉静、可靠、不制造焦虑（提醒分级用柔和色带而非刺眼红色警报）。
- **材质**：分层平面 + 发丝线描边（1px hairline），不依赖重投影与玻璃拟态。
- **能量**：克制。科技感来自**精度**（等宽数字、状态微光点、对齐），不来自霓虹与渐变。

参考谱系：Linear / Things 3 的克制与排版、Arc 的圆润与呼吸感、Haystack/首页仪表类的数据呈现，但**拒绝**其中不适配思源插件生态的部分（见 §6 禁止清单）。

## 2. 三条设计原则

1. **一个强调色**：`--lv-accent` 只用于"可执行"与"选中"；语义色（红橙黄绿）只用于状态，永不用于装饰。
2. **三级文字层次**：主 `--lv-tx` / 次 `--lv-tx-2` / 弱 `--lv-tx-3`，任何界面不允许第四种文字颜色。
3. **内容先于容器**：能用留白与分隔线表达分组时不加卡片；卡片只出现在"卡片本身可点击"处（模块卡、成员卡）。

## 3. Token 体系与 b3 映射

实现时代码作用域限定在插件容器（`.lv-home`）内；**有 b3 对应的 token 必须引用 b3 变量**（跟随主题切换），仅补齐 b3 没有的层级。

### 3.1 颜色

| token | 语义 | 思源 b3 对应 | 无 b3 时的自定义值（dark / light） |
|---|---|---|---|
| `--lv-bg` | 画布底 | `--b3-theme-background` | 继承 b3 |
| `--lv-surface` | 一级面板（卡片/表格/抽屉） | `--b3-theme-surface` | 继承 b3 |
| `--lv-surface-2` | 二级面（图标底/输入框/hover） | `--b3-theme-surface-light` | 继承 b3 |
| `--lv-line` | 发丝线 | `--b3-border-color` | 继承 b3 |
| `--lv-tx` / `-2` / `-3` | 三级文字 | `--b3-theme-on-background` / `on-surface` / `on-surface-light` | 继承 b3 |
| `--lv-accent` | 唯一强调色 | `--b3-theme-primary` | 继承 b3（用户主题色即插件强调色，天然跟随思源主题） |
| `--lv-accent-soft` | 强调色 10-14% alpha 衬底 | — | `rgba(primary,.14)` 以 color-mix 派生 |
| `--lv-danger/-warn/-amber/-ok` | 状态四级 | `--b3-card-error/warning/...-color` 参照 | dark: `#f2716f / #f0a35a / #e3c163 / #5cc48f`；light: `#d9484b / #c47717 / #a2821d / #1f9d64` |
| `--lv-danger-soft` 等 | 状态 8-11% alpha 衬底 | `--b3-card-error-background` 等可参照 | 同上派生 |
| `--lv-mask` | 遮罩 | `--b3-mask-background` | 继承 b3 |

### 3.2 其他

| 类别 | token | 值 |
|---|---|---|
| 圆角 | `--lv-r-1/2/3/4` | 6 / 10 / 14 / 18px（图标砖 10、卡片 14、抽屉弹层 18；思源 `--b3-border-radius*` 语义对齐） |
| 间距 | — | 4px 基数网格；区块间 26px；卡片内 16-20px |
| 阴影 | `--lv-shadow-1/2/3` | 微投影 / 悬浮 / 弹层（双层低透明度；dark 下更重） |
| 内侧高光 | `--lv-inset` | `inset 0 1px 0` 用于卡片/按钮/图标砖上缘（dark: `rgba(255,255,255,.045)`，light: `rgba(255,255,255,.7)`）——"受光边缘"是质感的主要来源 |
| 材质 | `--lv-aura` / `--lv-noise` | 页面顶部环境辉光（accent 5-8% alpha 径向渐变）与全屏胶片颗粒（SVG feTurbulence，2.8-4% 透明度）；均为 `body` 层非交互修饰 |
| 字体 | — | 继承 `--b3-font-family`；**所有数字用 `font-variant-numeric: tabular-nums`**（`.num`）；块 ID 等技术信息用 `.mono` |
| 字号 | — | 11.5 辅助 / 12.5 次要 / 13.5 正文 / 15 小标题 / 24-26 页标题（密度工具界面的克制阶梯） |
| 动效 | `--lv-t-fast/med/slow/sheet` | 120 / 180 / 240 / 320ms；缓动 `--lv-ease: cubic-bezier(.2,0,0,1)`（界面位移）与 `--lv-spring: cubic-bezier(.32,.72,0,1)`（抽屉/弹层/胶囊等"有分量"物体的出入场）；思源 `--b3-transition` 语义一致 |
| 模块色砖 | `.t-blue/-green/-cyan/-purple/-rose/-amber` | 领域色调：12% alpha 底 + 26% 同色描边；只用于模块/功能图标砖（辨识职能），不扩散到别处 |

## 4. 组件规范（对应原型六屏）

| 组件 | 规则 |
|---|---|
| 顶栏 | 产品标（渐变砖是全产品唯一渐变）+ 分段导航（胶囊滑动选中）+ 提醒中枢状态点（绿色微光=已扫描，`mono` 显示时间）+ ⚡ 快速记录 |
| 成员 chips | 全局过滤器；激活态 = accent 衬底；头像用成员色圆点；`＋` 收尾 |
| 提醒行 | 3px 严重度色轨（left rail）+ 34px 图标砖 + 标题/来源两级 + 右侧"人类时间"（"3 天后"比日期优先）+ **hover 才出现操作按钮**（静默时不制造焦虑） |
| 模块卡 | 仅此处的卡片是入口；**领域色图标砖**（t-blue/green/cyan/purple/rose/amber）+ 名称 + 一个关键统计（条数/月均/净额）+ 可选 5 根迷你趋势条（入场 scaleY 生长、hover 高亮）；hover 上浮 2px |
| 成员卡 | 渐变头像（每人固定色相 + 内侧高光）+ 三格统计 + 长期进度用 3px 渐变细进度条（如疫苗程序 14/22）+ 待办 alert 行（⚠/◦ 两级） |
| 台账表 | 发丝线行、吸附表头、首列 8px 状态微光点（带 3px 光晕）；选中行 = accent 衬底 + 2px 左指示；副信息 11.5px 弱色 |
| 详情抽屉 | 440px 右滑入 + 蒙层模糊；kv 两列栅格；附件为文件胶囊；底部动作区主按钮=续期；块 ID 用 mono 弱色展示（双链可复制） |
| 快速录入 | 480px 中央弹层；capture 列集驱动；"顺手建档"联动选项；记住上次模块 |
| 设置 | 左侧分区导航 + 右侧分区块；模块行 = 名称+一句话+徽章（核心/建议成员）+ 开关；开关即时生效 |
| 空态 | 图标砖 + 一句话 + 下一步动作；禁止装饰性插图与空洞文案 |
| 引导 | 唯一允许 aura 光晕背景的界面（品牌时刻）；角色 chips 即选择 |

## 5. 动效规范（v1.1）

**编排原则**：动效分三层——入场编排（每屏一次）、共享过渡（导航胶囊）、微反馈（悬浮/按压）；全部尊重 `prefers-reduced-motion`（整体降级为无动效）。

| # | 动效 | 参数 |
|---|---|---|
| 1 | **入场交错编排** | 屏幕激活时，直接子元素按 30-75ms 阶梯延迟依次上浮淡入（8-10px）；模块网格与趋势条（scaleY 生长）再晚一拍；抽屉内容同样编排。产生"界面在呼吸"的秩序感 |
| 2 | **导航胶囊滑动** | 分段控件激活胶囊以 `--lv-spring` 在项间滑动（共享布局过渡），宽高随内容 |
| 3 | **悬浮/按压微反馈** | 卡片 -2px 上浮 + 阴影升级 + 图标砖微旋转（-4°）；按钮按压下压 1px；提醒行操作按钮 hover 滑入；色轨 hover 泛光（`box-shadow: currentColor`） |
| 4 | **弹层出入场** | 抽屉/弹层用 `--lv-spring` 320ms（位移+缩放 0.97→1），蒙层同步淡入并模糊 |
| 5 | **状态点呼吸** | 全产品**唯一**常驻动效：提醒中枢状态点的 1px 光环 3.4s 缓慢扩散消散——表达"服务活着" |
| 6 | **数字滚动** | 总览计数入场 0→N（560ms，ease-out-cubic），仅此一处 |
| 7 | **品牌时刻** | 引导页 aura 双层光晕 11-13s 极缓漂移（唯一允许的装饰动画区） |

禁止：视差、数字滚动滥用、循环脉冲（状态点除外）、大面积位移常驻动画。

## 6. 禁止清单（与原型一致的红线）

- ❌ 仪表盘卡片马赛克（卡片必须可点击才存在）
- ❌ 常规产品界面背后的装饰渐变（仅引导 aura 一处豁免）
- ❌ 多强调色、霓虹配色、纯黑纯白
- ❌ 每个区域都加粗边框（用发丝线与留白分组）
- ❌ 第四种文字颜色、硬编码色值（实现必须走 token→b3 引用）
- ❌ 装饰性图标（每个图标承担辨识或状态职能）

## 7. 实现注记（v0.2 C 阶段）

1. 原型即验收基准：C1-C8 各界面按 `prototype/index.html` 对应屏实现，像素级以 token 体系为准。
2. 所有样式写入 `src/index.scss`，选择器一律 `.lv-home` 前缀作用域；token 定义在 `.lv-home[data-theme]` 由思源主题自动继承，**不设独立主题系统**。
3. b3 未覆盖的四个语义色与 soft 衬底以 `color-mix(in srgb, ...)` 从 b3 变量派生，保证用户自定义主题仍然协调。
4. 无外部字体、无图标库：导航图标用内联 SVG（产品标一处），其余用 b3 内置 icon 类或文字。
5. 原型文件不进入构建产物与发布 zip（`prototype/` 仅开发参考）。
