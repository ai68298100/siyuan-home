# 06 · v0.2 开发任务拆解（纵向切片：证件管理端到端）

> 目标：用一个模块（certs）打通"引导→建库→录入→附件→提醒→续期"全闭环，验证 [01 架构总览](./01-架构总览.md) 的全部 ADR，并定案 R1/R2 两个开放风险。
> 完成后 v0.3 起的模块生产均为"复制此模式"。

## 阶段 S · 架构 Spike（先行，2–3 天）

| 任务 | 内容 | 产出/验收 |
|---|---|---|
| S1 · R1 嵌入方式 | 三种台账视图承载各做最小样：① protyle 内嵌 av 块 ② 数据库 API 渲染自绘表格 ③ "在文档中打开"跳转 | 三样例截图 + 观感/稳定性/工作量对比表，**定案写入 01 ADR-4** |
| S2 · R2 关系列 | 验证数据库 relation 列可否编程创建并指向 members 库 | 可 → 字典列 `member` = relation；不可 → 降级文本列 + 成员页 SQL 聚合，**更新 02 §2** |
| S3 · 行定位能力 | 验证从提醒跳转并高亮台账行（R5） | 可行/降级结论写入 03 §5 |

## 明确不做（v0.2 范围外）

多模块批量建库（仅 certs + members）、生态 RPC 实现（设置页仅占位开关）、统计卡片汇总算法（certs 卡显示条数+到期数即可）、移动端专门优化、模板系统（certs 暂无长内容模板）。
