# 小驴管家 (Lv Home)

**一本会主动提醒你的家庭档案** —— 思源笔记的家庭与生活管家插件。

家庭私有档案库 · 全家到期提醒中枢 · 家庭事务工作台

## 定位

把散落各处的家庭信息收敛成本地优先、可检索、会主动提醒的一本家庭档案：

- **成员为一等公民**：自己 / 配偶 / 伴侣 / 子女 / 老人 / 其他亲属，证件、病历、保单、上学等一切台账按成员组织。
- **台账进思源数据库**：每模块一张数据库，行即块、可被日记双链引用；用户可见可改可自建视图，插件不锁数据。
- **效期进统一提醒中枢**：证件、药品、保单、订阅、年检、合同、退休……所有日期型字段走同一条提醒管道，提前量按类型可配。
- **模块按需开启**：6 大组 31 个模块，未启用的模块不建库、不出现在界面。有子女才被建议开"育儿/上学"，功能面广但默认轻。
- **工作与学习是场景**：职业证书走考证管理、劳动合同走合同管理、学习站点走网址库，不为它们单设模块。

## 明确不做

记账流水、密码库、官方数据对接（违章/保单/社保余额）、实时出行信息、条码出示、在线问诊、媒体在线播放。小驴管家只做**台账 + 提醒 + 归档**层。

## 开发

```bash
pnpm install
pnpm run dev      # 开发（app + kernel 双目标 watch）
pnpm run build    # 构建 dist/
pnpm run check    # TypeScript + Svelte + i18n 键位对齐
pnpm test         # 单元测试（规则引擎/提醒中枢）
```

实测回归清单见 [docs/testing/v0.2.md](./docs/testing/v0.2.md)；常见问题见 [docs/FAQ.md](./docs/FAQ.md)，隐私说明见 [docs/privacy.md](./docs/privacy.md)。

技术栈：思源插件模板 `plugin-sample-vite-svelte`（Vite 8 + Svelte 5 + pnpm，Node ≥ 24）。

- 模块注册表：`src/core/modules.ts`（加模块 = 一行注册 + i18n 文案）
- 设置持久化：`loadData/saveData` → `data/storage/petal/siyuan-home/`
- 台账本体（v0.2 起）：思源数据库（属性视图），不落插件私有存储
